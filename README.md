# Bare-Metal Embedded Systems Projects

This repository is where I document my move from HAL-based STM32 development
into bare-metal, register-level programming — working directly from
datasheets and reference manuals instead of relying on abstraction layers.

## Why This Repo Exists

I wanted a space to prove and track real, working hardware projects as I
build up register-level understanding across different microcontrollers,
protocols, and peripherals — not just course completions, but things that
actually run on real boards.

## How It's Organized

Each project lives in its own folder with a short overview README. Inside,
you'll find further subfolders with detailed, technical READMEs covering
hardware configuration, pin assignments, and code structure for that
specific piece.

Start at a project folder to get oriented, then go deeper from there.

## Note

This repo will keep growing as I take on new boards, protocols, and
peripherals. Check back for updates.
